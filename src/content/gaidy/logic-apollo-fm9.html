Краткий ответ и зафиксированный результат

Главный вывод

Текущая базовая конфигурация стала правильной после возврата Logic Pro → Settings → Audio → Devices → Recording Delay к 0 samples. Значение -5000 samples сдвигало записанный регион примерно на 104,2 мс раньше сетки при 48 кГц. Буфер 64 samples не был причиной этого постоянного опережения.

Архитектура студии

Рекомендуемая архитектура состоит из двух независимых систем и одного опционального моста. Это сохраняет быстрый автономный FM9, не создаёт лишний Aggregate Device и оставляет Apollo главным интерфейсом для проектов Logic Pro, вокала, DI-гитары и баса.

Что именно называется задержкой

1. Задержка мониторинга

Это время от игры или пения до звука в наушниках. Её определяет выбранный путь: прямой UAD Console или программный путь через Logic Pro. I/O Buffer Size влияет прежде всего на программный путь. При мониторинге через Console вход не совершает полный круг через Logic, поэтому 64 samples уже комфортны, а 128 samples часто тоже допустимы.

2. Задержка плагинов и проекта

Look-ahead limiter, linear-phase EQ, oversampling, convolution и некоторые UAD DSP-плагины могут задерживать playback или live path. Logic Pro компенсирует задержку воспроизведения при Plug-in Latency Compensation = All, но музыкант всё равно может слышать поздний метроном, если тяжёлый мастеринг-плагин стоит на Stereo Out. В нагруженном проекте включайте Low Latency Mode на время overdub или временно выключайте тяжёлые плагины.

3. Позиция записанного региона

Это отдельная задача. Apollo сообщает Logic Pro аппаратную и driver latency, а Logic размещает файл на таймлайне с компенсацией. Recording Delay добавляет постоянную ручную поправку поверх driver report. При -5000 samples Logic применял лишний сдвиг: 5000 / 48000 = 0,10417 секунды. Поэтому дорожка оказывалась раньше метронома, хотя в наушниках задержки не было.

Практический критерий

Если ощущение в наушниках плохое — проверяйте monitoring path, buffer и плагины. Если исполнение ощущалось нормально, но регион систематически стоит раньше/позже — проверяйте Recording Delay, драйвер и loopback. Не лечите одно другим.

Режимы мониторинга

Режим A — UAD Console direct monitoring (рекомендуемый default)

Когда выбирать

Вокал, DI-гитара, бас, микрофон усилителя; особенно когда нужны минимальная задержка и UAD DSP-эффекты в наушниках.

  1. [UAD Console] На нужном Analog input откройте нижнюю секцию fader/pan. Кнопка M должна быть выключена — канал не заглушён.
  2. [UAD Console] Для стандартных insert-плагинов включите UAD MON, если хотите слышать обработку, но записывать dry.
  3. [Logic Pro → Settings → Audio → General] Software Monitoring = Off.
  4. [Logic Pro → Track header] Record Enable R = On; Input Monitoring I = Off.
  5. [Logic Pro → Settings → Audio → Devices] Buffer = 64 samples; Recording Delay = 0.
  6. [Logic Pro] Если проект уже нагружен, включите Low Latency Mode и временно выключите look-ahead/linear-phase/oversampling плагины на Stereo Out.

Режим B — software monitoring через Logic Pro

Когда выбирать

Когда звук должен формироваться плагином Logic Amp Designer, Neural DSP, Guitar Rig или native/UADx-плагином в Logic во время исполнения.

  1. [UAD Console] На входном Analog channel нажмите M, чтобы прямой путь Console не звучал.
  2. [Logic Pro → Settings → Audio → General] Software Monitoring = On.
  3. [Logic Pro → Track header] Input Monitoring I = On и Record Enable R = On.
  4. [Logic Pro → Settings → Audio → Devices] Начните с I/O Buffer 32. Если появляются щелчки — 64.
  5. [Logic Pro → Settings → Audio → General] Low Latency Monitoring Mode = On, Limit 5–10 ms.
  6. [Logic Pro → Audio track inserts] Оставьте только низколатентные плагины. Выключите oversampling/high-quality режимы до сведения.
Симптом двойного пути

Если голос или гитара звучат как phaser/comb filter, раздвоены или неожиданно громкие — одновременно слышны Console и Logic. Либо заглушите вход Console, либо выключите Software Monitoring в Logic.

Безопасное правило

Если сомневаетесь — не ставьте amp/preamp в dedicated Unison slot и держите standard inserts в UAD MON. Так вы получите вдохновляющий звук в наушниках и сохраните чистый материал.

Конфигурации записи

Конфигурация 1 — гитара прямо в Apollo, слышать amp, записывать DI

Это основной рекомендуемый режим для домашних экспериментов: исполнение ощущается как через усилитель, но аудиофайл остаётся пригодным для Amp Designer, Neural DSP, Guitar Rig, UAD amp или re-amp позднее.

  1. [Подключение] Гитара → передний Hi-Z вход Apollo Analog 1. Phantom 48V = Off.
  2. [UAD Console → Analog 1] Input = Hi-Z. Для amp-плагина не используйте Auto-Gain; UA рекомендует минимальный preamp gain на Hi-Z с amp plug-ins. UA-7
  3. [UAD Console → Unison] Оставьте dedicated Unison slot пустым, чтобы ничего не печатать.
  4. [UAD Console → standard inserts] Опционально: Raw Distortion → Marshall Plexi Classic → лёгкий 1176/LA-2A. Global/Channel mode = UAD MON.
  5. [UAD Console → AUX 1] Pure Plate 100% wet; send по вкусу. Это comfort effect.
  6. [Logic Pro] Mono audio track, Input 1, R On, I Off. Записывается clean DI.
  7. [Logic Pro] После записи добавьте Amp Designer/Neural/UADx на track insert или сделайте отдельную printed copy через Bounce in Place.

Конфигурация 2 — гитара прямо в Apollo, записать готовый UAD amp

  1. [UAD Console → Analog 1] Соберите Marshall Plexi Classic и необходимые effects в standard inserts.
  2. [UAD Console → Channel Insert Effects] Переключите только этот канал в UAD REC. Не обязательно переводить глобально все входы.
  3. [Logic Pro] Mono track Input 1, R On, I Off. Сделайте короткий тест и перепроверьте тон до полного дубля.
  4. [Logic Pro] Назовите дорожку, например GTR_Plexi_PRINT, и запишите preset/положение гитары в Track Notes.
Ограничение

Обычный Apollo input в этом режиме отдаёт в Logic выбранный вариант — dry при MON или wet при REC. Для надёжного одновременного dry+wet live-захвата используйте внешний split/DI или записывайте dry с MON и печатайте обработанную копию после дубля.

Конфигурация 3 — гитара через плагины Logic / Neural DSP

  1. [UAD Console] Analog 1 Mute = On; Unison и standard inserts пустые.
  2. [Logic Pro → Settings → Audio] Software Monitoring On; buffer 32/64; Low Latency Mode On.
  3. [Logic Pro → audio track] I On, R On. На insert поставьте Amp Designer, Neural DSP или Guitar Rig.
  4. [Logic Pro → Stereo Out] На время записи bypass look-ahead limiter, linear-phase EQ, oversampling и тяжёлые mastering chains.
  5. [Logic Pro] После записи файл остаётся dry, плагины можно менять или удалить.

Конфигурация 4 — бас прямо в Apollo

  1. [Подключение] Bass → Apollo Hi-Z. 48V Off.
  2. [UAD Console → Unison] Для полностью обратимого варианта оставить пустым.
  3. [UAD Console → standard inserts] Ampeg SVT-VR Classic → LA-2A Legacy; mode UAD MON.
  4. [UAD Console] Цель уровня clean DI: обычные пики примерно -12…-6 dBFS, без красного clip.
  5. [Logic Pro] Mono Input 1, R On, I Off. Сохранить clean bass DI.
DUO DSP

Ampeg SVT-VR Classic использует заметную долю DSP. На Apollo DUO держите tracking-chain простой, а Pure Plate размещайте один раз на AUX, не отдельным instance на каждом канале. UA-13

Конфигурация 5 — вокал Oktava MK-105, безопасный dry

  1. [Подключение] MK-105 → Apollo rear XLR Mic input. Поп-фильтр. Микрофон side-address: петь в рабочую сторону капсюля.
  2. [UAD Console → Analog input] Mic, 48V On, Pad Off как default, polarity normal. MK-105 требует 48V. Oktava-1
  3. [UAD Console] Ручной gain или Auto-Gain при самой громкой реальной подаче. Цель: пики около -12…-6 dBFS; не стремиться к 0 dBFS.
  4. [UAD Console → Unison] Оставить пустым для полностью dry capture.
  5. [UAD Console → standard inserts] Century Tube Channel Strip и/или Auto-Tune Realtime Access в UAD MON; Pure Plate на AUX.
  6. [Logic Pro] Mono track Input 1/2, R On, I Off. Recording Delay 0.
  • [UAD Console → Century] Используйте Low gain как отправную точку для современного condenser; EQ минимальный. У MK-105 уже есть подъём присутствия, поэтому не добавляйте автоматически верх.
  • [UAD Console → Auto-Tune Realtime Access] Включать только при известной тональности. Из-за динамической latency Auto-Tune не является инструментом измерения тайминга; при сомнении используйте только MON. UA-4
  • [UAD Console → AUX Pure Plate] Wet Solo On, low cut 180 Hz, pre-delay 35–65 ms, decay 1.5–2.5 s. Вокал остаётся разборчивым, а реверберация не печатается в основной track.

Конфигурация 6 — вокал Shure SM58

  1. [Подключение] SM58 → Apollo rear XLR Mic input. 48V Off. Рабочая дистанция примерно 3–10 см; для plosives повернуть микрофон на 10–20°.
  2. [UAD Console] Gain потребуется больше, чем с MK-105. Пики по-прежнему держать около -12…-6 dBFS.
  3. [UAD Console → standard insert] Century Tube Channel Strip: High gain может лучше подходить динамическому микрофону, но следите за noise floor. UAD MON.
  4. [Logic Pro] R On, I Off при Console monitoring. Файл dry.

SM58 — cardioid dynamic vocal microphone с диапазоном 50 Hz–15 kHz и выраженным proximity effect. Он лучше изолирует комнату, но требует более близкой работы и большего preamp gain. Shure-1

Конфигурация 7 — педалборд перед Apollo

  1. [Подключение] Guitar → pedalboard → Apollo Hi-Z. Если последний pedal выдаёт line-level или очень высокий level, снизьте output и контролируйте клиппинг.
  2. [UAD Console] Hi-Z, 48V Off. Начать с минимального gain.
  3. [UAD Console] Amp simulation в standard insert UAD MON; modulation/delay можно оставить на pedalboard или Console AUX.
  4. [Logic Pro] Записываемый DI уже содержит необратимую обработку физическими педалями. Назовите дорожку GTR_PEDAL_DI и запишите chain в Notes.

Конфигурация 8 — Marshall TSL602 через микрофон

  1. [Подключение] SM58 → Apollo Mic input; начать у края dust cap, 2–5 см от grille, затем искать баланс яркости перемещением к центру/краю.
  2. [UAD Console] Mic, 48V Off для SM58. Pad включать только если Apollo input перегружается при минимальном gain.
  3. [Logic Pro] Mono track. Console monitoring. Сделать 15-секундный тест и проверить шум, фазу и низ до полного дубля.
  4. [Опционально] Одновременно получить независимый safety DI можно внешним DI/splitter; один микрофонный канал сам по себе такой DI не создаёт.
MK-105 на кабинете

MK-105 рассчитан примерно до 124 dB SPL и технически может использоваться на кабинете, но для домашней задачи SM58 проще и безопаснее по размещению. Не направляйте condenser вплотную на экстремально громкий кабинет без контроля SPL и input headroom. Oktava-1

Fractal FM9: три рабочих сценария

FM9 как автономная система

Это ваша постоянная быстрая схема: Guitar → FM9 → OUT 1 → Yamaha MSP5. Logic Pro и Apollo в ней не участвуют. Сохраняйте её как независимую, чтобы включить FM9 и играть без перенастройки студии.

FM9 по USB в Logic: processed + DI

  1. [FM9 / FM9-Edit] Подключите USB к Mac. Preset должен завершаться OUT 1. Sample rate FM9 фиксирован 48 kHz.
  2. [Logic Pro → Settings → Audio → Devices] Input Device = FM9; Output Device = FM9. Buffer 64/128. Recording Delay 0.
  3. [Logic Pro → Project Settings → Audio] Sample Rate = 48 kHz.
  4. [Logic Pro → Track 1] Stereo input FM9 1/2, имя GTR_FM9_PRINT — это то, что слышно на main outputs.
  5. [Logic Pro → Track 2] Mono input FM9 5, имя GTR_FM9_DI — чистый Instrument Input.
  6. [Logic Pro → Settings → Audio → General] Software Monitoring Off. На tracks I Off; R On.
  7. [FM9] Слушайте напрямую через Yamaha на OUT 1. Запишите обе дорожки.
Уточнение канала DI

Чистая гитара FM9 записывается как mono Input 5, а не stereo 5/6. Inputs 1/2 — processed stereo. Это прямо указано в официальной процедуре re-amping Fractal. Fractal-2

USB re-amp через FM9

  1. [FM9 → Setup → I/O → Audio] Digital Input Source = USB Channels 5/6; Input 1 Source = Digital.
  2. [Logic Pro → DI track] Output = FM9 Output 5. Отключите Software/Input Monitoring на recording track.
  3. [Logic Pro → new stereo track] Input = FM9 1/2, R On. Назовите GTR_FM9_REAMP_01.
  4. [FM9] Выберите/отредактируйте preset и запишите re-amped result.
  5. [FM9 → Setup → I/O → Audio] После завершения обязательно вернуть Input 1 Source = Analog.

FM9 OUT 2 → Apollo Line 1/2

  1. [Кабели] FM9 OUT 2 L/R XLR → два balanced cable XLR-F to TRS → Apollo rear TRS Inputs 1/2. Не подключать XLR-XLR в Apollo, иначе это Mic input.
  2. [FM9 / FM9-Edit] Добавьте OUT 2 block в конце chain или включите Copy OUT 1 → OUT 2, если этот параметр подходит текущему preset.
  3. [UAD Console → Analog 1/2] Input = Line, stereo link On, 48V Off, Pad Off. Line Input Gain = BYPASS для чистого fixed-reference path, если доступен.
  4. [UAD Console] Input channel unmuted, standard inserts пустые или UAD MON.
  5. [Logic Pro] Stereo audio track Input 1/2, R On, I Off. Monitor through Apollo/iLoud.
  • Плюс: Apollo остаётся интерфейсом проекта, метроном и все tracks идут в iLoud.
  • Минус: FM9 signal проходит D/A → A/D и занимает оба analog inputs Apollo.
  • Ограничение: это один processed stereo pair. Для processed + независимого DI используйте USB FM9.
  • FM9 OUT 1 → Yamaha остаётся неизменным, поэтому автономный режим сохраняется.
S/PDIF не default

FM9 имеет coaxial S/PDIF 48 kHz, а Apollo Twin X принимает optical S/PDIF. Потребуется активный coax-to-optical converter и Apollo Clock Source = S/PDIF. Это убирает лишний D/A-A/D, но усложняет clocking и даёт лишь один stereo pair. Для вашей задачи analog OUT 2 проще.

Сведение: оптимальные настройки

Главный принцип

Во время сведения Console используется как monitor controller и I/O, а обработка mix живёт в Logic Pro. Плагины на Console input strips не обрабатывают уже записанные tracks Logic.

  1. [Logic Pro → Settings → Audio → Devices] I/O Buffer Size = 512. Если CPU/проект тяжёлый — 1024.
  2. [Logic Pro → Settings → Audio → Devices] Process Buffer Range = Large; Processing Threads = Automatic; Multithreading = Playback & Live Tracks; Summing = High Precision 64-bit.
  3. [Logic Pro → Settings → Audio → General] Plug-in Latency Compensation = All; Low Latency Mode = Off; Software Monitoring = Off.
  4. [UAD Console] Input channels можно mute, если ничего не записывается. Monitor path на iLoud оставить без дополнительных insert EQ/correction.
  5. [ARC X / iLoud] Загрузить сохранённую hardware session, Room Correction On, Bypass Off. Не вставлять ARC X plug-in на Logic Stereo Out.
  6. [Logic Pro → Stereo Out] Master processing добавлять осознанно; при возврате к overdub выключить high-latency processors или включить Low Latency Mode.

Level matching

Любой плагин кажется «лучше», если он просто громче. При сравнении bypass выравнивайте output level примерно до одинаковой воспринимаемой громкости.

Мониторы, сабвуфер и ARC X

По присланной сессии ARC X система определена как Stereo + Sub, калибрована и имеет статус OK. Left/Right имеют рассчитанный gain +2.5 dB, Sub -5.0 dB, delays 0.00 ms, Room Correction On, Phase Natural, диапазон 20 Hz–20 kHz. Эти значения являются результатом измерения и не требуют ручного копирования.

  • [ARC X] Bypass Off для критического прослушивания; Bypass можно кратко использовать как контроль, но не смешивать часть проекта в одном состоянии, часть в другом.
  • [Logic Pro] Не добавлять ARC X plug-in на Stereo Out при уже активной аппаратной коррекции — это даст двойную коррекцию.
  • [Apollo] Громкость регулировать Monitor knob; не менять индивидуально уровни MTM/Sub после калибровки.
  • [ARC X] Перекалибровать после перемещения мониторов/саба/стола, серьёзного изменения акустики или точки прослушивания.
  • [Logic Pro] Hardware ARC находится после аналогового выхода Apollo, поэтому offline/online bounce остаётся некорректированным и пригодным для передачи.
Акустика остаётся важной

ARC X исправляет response, level, phase/time alignment в пределах возможностей системы, но не устраняет длинные модальные затухания, ранние отражения и плохую геометрию. Текущая частичная обработка полезна; финальные решения по низу дополнительно проверяйте на Yamaha, headphones и бытовых системах. IK-1

Передача проекта или партий в студию

  1. [Logic Pro → Project Settings → Audio] Сохранить исходный sample rate 48 kHz. Не менять проект на 44.1 kHz перед экспортом.
  2. [Logic Pro → Recording settings] Запись/экспорт WAV 24-bit; не нормализовать individual tracks.
  3. [Logic Pro → Export] Все файлы начинать от одной позиции, например bar 1 beat 1; сохранить tempo map и count-in отдельно.
  4. [Logic Pro] Для гитары и баса отдавать clean DI + processed reference. Для FM9 — GTR_FM9_DI mono + GTR_FM9_PRINT stereo.
  5. [Logic Pro] Сделать два stereo reference: MIX_REF с вашей обработкой и PREMASTER без limiter/clipper, с запасом по уровню.
  6. [Notes] Приложить список tuning, BPM, sample rate, важные plugin/preset names, guitar/bass, pickup positions и creative intent.

Контрольный loopback-тест

Проводить только если после обновления драйвера/Logic снова появился постоянный систематический offset. Тест измеряет интерфейс и driver, а не музыкальную точность исполнения.

  1. [Кабель] Соединить Apollo Line Output 3 с Apollo rear TRS Line Input 1 balanced TRS–TRS. Наушники/monitor volume сделать безопасным.
  2. [UAD Console] Analog 1 = Line, Line Gain Bypass, input channel Mute On, чтобы исключить feedback. Все inserts пустые.
  3. [Logic Pro] Создать короткий audio click/impulse track и направить его на Output 3. Создать mono record track Input 1.
  4. [Logic Pro] Recording Delay = 0, Flex Off, Quantize Off. Записать 10–20 импульсов.
  5. [Logic Pro → Sample ruler / Sample Editor] Измерить разницу между исходным и записанным transient в samples. Повторить три раза.
  6. [Logic Pro] Если offset одинаков и не ноль во всех трёх тестах, только тогда ввести равную противоположную correction. Сохранить дату, sample rate, buffer и driver version.
  7. [UAD Console / кабель] После теста вернуть input к обычному режиму и удалить loopback cable.
Безопасность

Никогда не оставляйте loopback input unmuted в Console и не направляйте его обратно на тот же output — получится feedback loop.

Чек-листы

Перед каждой записью через Apollo

  • [Logic Pro] 48 kHz; Universal Audio Thunderbolt; buffer 64; Recording Delay 0.
  • [Logic Pro] Software Monitoring Off; PDC All; R On; I Off.
  • [UAD Console] Clock Internal; IDC Short; нужный input unmuted.
  • [UAD Console] 48V только для MK-105; Off для guitar/bass/SM58/FM9 line.
  • [UAD Console] UAD MON, если обработка не должна печататься; Unison empty для полностью dry.
  • [UAD Console] Пики обычно около -12…-6 dBFS, clip отсутствует.
  • [ARC X/iLoud] Hardware correction active; Logic ARC plug-in отсутствует.

Перед записью через FM9 USB

  • [FM9] USB подключён; preset звучит через OUT 1/Yamaha; firmware 12.0.
  • [Logic Pro] Input/Output Device FM9; 48 kHz; buffer 64/128; Recording Delay 0.
  • [Logic Pro] Software Monitoring Off; I Off.
  • [Logic Pro] Processed stereo = Inputs 1/2; clean DI mono = Input 5.
  • [FM9] После re-amp вернуть Input 1 Source = Analog.

Перед сведением

  • [Logic Pro] Buffer 512/1024; Process Buffer Large; PDC All; LLM Off.
  • [Logic Pro] Все live input monitoring выключено; лишние record-enable сняты.
  • [Logic Pro] ARC X не стоит на Stereo Out.
  • [ARC X/iLoud] Correct profile загружен, Bypass Off.
  • [Logic Pro] Reference tracks level-matched и обходят лишний master coloration при сравнении.
  • [Прослушивание] Проверка iLoud + Yamaha + headphones + бытовая система на умеренной громкости.

Версионирование и обслуживание

  • После обновления Logic Pro, macOS или UAD сделать 30-секундный test project: click + DI, Recording Delay 0.
  • Сохранить UAD Console Session: APOLLO_TRACK_DRY_MON и отдельную APOLLO_TRACK_LOGIC_MON. Во второй input channels должны быть muted.
  • Сохранить Logic template с 48 kHz, buffer-control в Control Bar, PDC All, Recording Delay 0 и заранее названными DI/PRINT tracks.
  • Сохранить FM9 preset/template с OUT 1 для Yamaha и OUT 2 в конце chain для опционального Apollo bridge.
  • ARC X recalibration делать после физического изменения комнаты/мониторов, а не по календарю без изменений.
  • Перед загрузкой старой UAD Console session проверять 48V: Console session может восстановить аппаратные preamp settings. UA-3
